## 2.3 `link_screenshot` 的 COALESCE 写法

`storage/db.py:760-778` 逐字：

```python
    def link_screenshot(self, hotel_id: int, collect_date: str, page: str,
                        screenshot_path: Optional[str] = None,
                        module_screenshots: Optional[dict] = None) -> bool:
        """截图通道回填：把独立截图器的产物挂到采集记录（Phase 2 T2.3 截图解耦）。"""
        if module_screenshots is None:
            module_screenshots = {}
        with self._write_lock, self._conn() as conn:
            cur = conn.execute(
                """
                UPDATE collect_reports
                SET screenshot_path = COALESCE(?, screenshot_path),
                    module_screenshots_json = COALESCE(?, module_screenshots_json)
                WHERE hotel_id=? AND collect_date=? AND page=?
                """,
                (screenshot_path,
                 json.dumps(module_screenshots, ensure_ascii=False) if module_screenshots else None,
                 hotel_id, collect_date, page),
            )
            return cur.rowcount > 0
```

**COALESCE 写法原文（`storage/db.py:770-771`）**：

```sql
                SET screenshot_path = COALESCE(?, screenshot_path),
                    module_screenshots_json = COALESCE(?, module_screenshots_json)
```

**语义要点**

| 项 | 语义 | 行号 |
|---|---|---|
| `COALESCE(?, 旧值)` | 传入 `NULL` → 保留旧值；传入非 `NULL` → 覆盖 | `770-771` |
| 传 `None` 的两种途径 | ① `screenshot_path=None`（`screenshoter.py:517`）→ 保留旧 `screenshot_path` | `517` |
| | ② `module_screenshots` 为空 dict → 表达式 `if module_screenshots else None` 判空 → 传 `None` → **保留旧值**（注意：空 dict **不会**清空旧值） | `775` |

| 返回 | `cur.rowcount > 0`（`UPDATE` 是否命中行；**行不存在时返回 `False`，不会插入**） | `778` |
| 事务 | `with self._write_lock, self._conn() as conn:`（写锁 + 连接上下文） | `766` |

### 2.4.3 读取侧（合并语义）

```python
    def today_module_shots(self, hotel_id: int, collect_date: str) -> dict[str, str]:
        """合并该酒店当日各页 module_screenshots → {截图模块名: 相对路径}（首见优先）。

        轮换推送取图（2026-08-25）：Screenshoter 按页落库(collect_reports.module_screenshots_json)，
        跨页合并后供 app.rotation.pick_screenshot 按 alias 选择。
        """
        out: dict[str, str] = {}
        with self._conn() as conn:
            rows = conn.execute(
                "SELECT module_screenshots_json FROM collect_reports "
                "WHERE hotel_id=? AND collect_date=?",
                (hotel_id, collect_date),
            ).fetchall()
        for r in rows:
            try:
                shots = json.loads(r["module_screenshots_json"] or "{}")
            except (TypeError, json.JSONDecodeError):
                continue
            if isinstance(shots, dict):
                for k, v in shots.items():
                    if k not in out:
                        out[k] = v
        return out
```

- 解析失败（`TypeError` / `JSONDecodeError`）静默 `continue`（`796-797`）；非 dict 静默跳过（`798`）。

## 2.5 `screenshot_path` 列与 `module_screenshots_json` 的关系

| 维度 | `screenshot_path` | `module_screenshots_json` |
|---|---|---|
| DDL | `TEXT`（`db.py:232`） | `TEXT`（`db.py:231`） |

def load_rotation(path: Optional[Path] = None) -> dict[str, Any]:
    """加载并校验轮换清单；返回 {"daily_count": int, "items": [...]}。"""
    p = Path(path) if path else DEFAULT_ROTATION_PATH
    if not p.exists():
        raise RotationError(f"轮换清单不存在: {p}")
    try:
        data = json.loads(p.read_text(encoding="utf-8"))
    except (json.JSONDecodeError, OSError) as exc:
        raise RotationError(f"轮换清单解析失败（{p}）: {exc}") from exc
    if not isinstance(data, dict):
        raise RotationError(f"轮换清单需为对象（{p}）")
    daily_count = data.get("daily_count", 5)
    if not isinstance(daily_count, int) or daily_count <= 0:
        raise RotationError("daily_count 需为正整数")
    items = data.get("items")
    if not isinstance(items, list) or not items:
        raise RotationError("items 需为非空数组")
    for i, item in enumerate(items):
        if not isinstance(item, dict) or not isinstance(item.get("name"), str) or not item["name"]:
            raise RotationError(f"items[{i}].name 需为非空字符串")
        if not isinstance(item.get("page"), str) or not item["page"]:
            raise RotationError(f"items[{i}] ({item.get('name')}).page 需为非空字符串")
        if not isinstance(item.get("type", "module_screenshot"), str):
            raise RotationError(f"items[{i}].type 需为字符串")
    return {"daily_count": daily_count, "items": items}

### 3.2.2 轮换算法 `rotation.py:60-66`（**原文逐字**）

```python
def daily_rotation(items: list[dict], day: date, count: int) -> list[dict]:
    """按日期偏移取连续 count 张（循环）；count 超过 items 长则全量。"""
    if not items:
        return []
    n = min(max(count, 1), len(items))
    offset = day.toordinal() % len(items)
    return [items[(offset + k) % len(items)] for k in range(n)]
```

def screenshot_demand_modules(d: date) -> set[str]:
    """今日截图需求模块名（与数据采集同源，report_schedule 单一事实源）。

    - ``windows_for_module`` 返回 ``([], [])`` → 当日不采集 → 截图也不截（如仅周期桶模块
      服务质量对比/同行对比 周三——甲方口径 2026-08-26：数据和截图一体，要就都要）；

    """某 item 在某日期应采集的窗口：``(priority, must)``。

    - ``priority``：每日基础窗口（daily 桶），按『今日实时/实时 优先于 昨日』排序，
      采集时按序尝试、首个有数据即止（甲方口径：有实时优先实时，实时无数据再采昨日）；
      ``daily_except_monday`` 且周一 → 空（与推送 item_windows_for_date 一致）；

      推送需要周期数据）；
    - 仅配周期桶的模块（无 daily）→ priority 空、must 只在触发日非空（特殊模块不走择优，

        others = [w for w in daily if w not in _REALTIME_WINDOWS]
        priority = realtime + others
    for b in ("monday", "month1"):
        if b in buckets_for_date(d) and b in windows:
            must.extend(windows[b])
    return priority, must
