## §0 一句话结论 + 旧比价域真实能力边界

### 0.1 一句话结论

**旧系统比价编排层是一条「能跑通、能出文字、能存档，但所有"智能"环节都已死或从未接线」的流水线**：生产实际执行路径 = 每店开一个浏览器 → 携程/美团**列表页 DOM 抓 3 条"附近酒店"的名字+价格** → 拼成 markdown → 写 SQLite → 以**纯文字**推企微；而 `geo` 距离排序、视觉读价（GLM-4.6V）、报告截图、单店定时比价**四条能力全部零生效**（§4/§10/§1.4/§1.3 逐条证据），判重逻辑虽存在却被 `force=True` 绕过，实测同日 `(anchor_name, query_date, nights)` 重复 **6 组 / 10 行冗余**（§3.4）。

### 0.2 真实能力边界（能 / 不能）

| 维度 | 旧系统实际能做到 | 依据 |
| --- | --- | --- |
| 平台覆盖 | 携程 + 美团，**双线程并行**，店内互不阻断 | `batch.py:62-71` |
| 采集口径 | 「锚点酒店名」→ 该店**列表页**上的「为您推荐附近的酒店 / 推荐卡片」；**不点地图、不进竞品详情页** | `ctrip.py:335-353`、`meituan.py:519-533` |
| 单店产出量 | 最多 `HOTEL_MAP_COUNT`（默认 3）家 × 2 平台 | `ctrip.py:283`、`meituan.py:477`、`config.py:110` |
| 价格来源 | **100% DOM 正则**（实测 92 条报价 `source` 全为 `"DOM"`） | `ctrip.py:372`、`meituan.py:557`、§3.5 实测 |
| 视觉读价 | **从未生效**（无 Key + 唯一调用点是死代码 + 批量路径根本不调） | §10 |

| 不可做 | 无「同店同日期唯一」约束；无价格走势结构化查询（只能 `json` 反序列化）；无失败重试队列 | §3.2 / §12 |

### 1.2 `_merge_quotes` 合并/去重算法（`runner.py:85-115`）原文照抄

```python
def _merge_quotes(payload: dict[str, Any], mode: str, nearby_count: int) -> list[dict]:
    """跨平台同名酒店合并，按距离排序取前 N 家。"""
    all_quotes: list[dict] = []
    for p in (payload.get("platforms") or {}).values():
        for q in p.get("quotes") or []:
            if q.get("name"):
                all_quotes.append(q)
    merged: dict[str, dict] = {}
    for q in all_quotes:
        key = norm_hotel_name(q.get("name", ""))
        if not key:
            continue
        if key not in merged:
            merged[key] = dict(q)
            merged[key]["platforms"] = [q.get("platform")]
        else:
            old = merged[key]
            old.setdefault("platforms", []).append(q.get("platform"))
            if (q.get("distance_km") is not None
                    and (old.get("distance_km") is None or q["distance_km"] < old["distance_km"])):
                old.update(distance_km=q["distance_km"], url=q.get("url"))
            if old.get("price") is None and q.get("price") is not None:
                old.update(price=q["price"], source=q.get("source"),
                           vision_price=q.get("vision_price"), dom_price=q.get("dom_price"))
            if q.get("cross_check"):
                old["cross_check"] = q["cross_check"]
    ranked = sorted(
        (v for v in merged.values()),
        key=lambda x: (x.get("distance_km") is None, x.get("distance_km") if x.get("distance_km") is not None else 1e9),
    )
    return ranked[:nearby_count]
```

算法要点与**实测缺陷**：

| 项 | 事实 | 行号 |
| --- | --- | --- |
| 去重键 | `norm_hotel_name(name)`（去空白/去括号内容/去业态后缀/小写） | `runner.py:94`；`human.py:221-228` |
| 数据来源 | 只读 `payload["platforms"][*]["quotes"]`，**不读 `hits`** | `runner.py:88-91` |
| 合并策略 | 首次出现 `dict(q)` 全量拷贝；后续只补 `platforms` 列表、**仅在 `price is None` 时**补价格 | `runner.py:97-108` |
| **缺陷 1：丢双平台价** | 第二个平台的价格**永远被丢弃**（`price` 已被第一个平台填满），`platforms` 数组记了两个平台却只有一个价 → **跨平台比价在单店路径上失效** | `runner.py:106-108` |
| **缺陷 2：`mode` 是死参数** | 函数签名收 `mode`，函数体内**从未使用**；`HOTEL_RANK_MODE=platform`（平台推荐顺序）**没有任何实现** | `runner.py:85`（签名）vs `85-115`（全体） |
| 排序 | 有距离的升序在前，`None` 全部沉底（`1e9` 哨兵） | `runner.py:111-114` |
| 截断 | `ranked[:nearby_count]` | `runner.py:115` |
| 实测 | DB `id=37`（唯一一条 `mode=geo` 记录）quotes=3，`distance_km` 全 `None` → 排序退化为**插入顺序** | §3.5 实测 |

### 1.3 为什么「取 2N 再截 N」（`runner.py:162` 附近）

```python
            result = plat.collect(anchor_name, date, checkout, nights,
                                  nearby_count=nearby_count * 2, headless=headless,
                                  **({"city": _city} if _city else {}))
```
（`runner.py:161-163`；重试分支 `runner.py:167-169` 同样用 `nearby_count * 2`）

**原因（由代码结构唯一可推的因果）**：每个平台先各返 `2N` 家 → `_merge_quotes` 按 `norm_hotel_name` **跨平台去重**（同名酒店两平台合成 1 条）→ 去重后条数必然 ≤ `2N` 且通常 < `2N` → 最后 `ranked[:nearby_count]` 截回 N（`runner.py:115`）。
即：**2N 是为了抵消跨平台同名去重造成的收缩，保证去重后仍能凑满 N 家**。若不放大，携程+美团各 N 条去重后可能只剩 N/2 条，最终报价不足。

> 注意该放大**只在单店路径生效**；批量路径 `batch.py` 不做跨平台合并（`batch.py:94` 注释原文「两个平台的数据分开生成报价条目（不合并）」），因此批量路径**没有** 2N 逻辑。

**格式解析原文**（`batch.py:15-27`）：

```python
def parse_hotel_list(path: Path | str) -> list[dict[str, Any]]:
    """解析酒店清单：每行一个酒店名，可选 `酒店名|城市`；空行与 # 注释忽略。"""
    tasks: list[dict[str, Any]] = []
    for raw in Path(path).read_text(encoding="utf-8").splitlines():
        line = raw.strip()
        if not line or line.startswith("#"):
            continue
        parts = [p.strip() for p in line.split("|")]
        name = parts[0]
        if not name:
            continue
        tasks.append({"name": name, "city": parts[1] if len(parts) > 1 and parts[1] else None})
    return tasks
```

规则：`utf-8` 读取、`strip()` 每行、空行/`#` 开头跳过、`|` 分割、`parts[0]`=酒店名（空则跳过）、`parts[1]`（若存在且非空）=城市，**第 3 个及以后的字段被静默丢弃**（`parts[1]` 取值，`batch.py:26`）。

### 2.2 `should_run_batch`（`batch.py:248-266`）「以数据为准的判重」完整代码原文

```python
def should_run_batch(file_path: Optional[Path | str] = None, date: Optional[str] = None,
                     nights: int = 1, store: Optional[PriceStore] = None) -> bool:
    """启动/定时判断：今天清单酒店的真实数据没覆盖完 → 需要跑。

    以「有没有数据」为准（演示数据不算），而不是"今天跑没跑过"。
    """
    store = store or PriceStore(Config.HOTEL_PRICES_DB)
    file_path = file_path or Config.resolve_hotel_batch_list()
    if not Path(file_path).exists():
        return False
    tasks = parse_hotel_list(file_path)
    if not tasks:
        return False
    date = date or (datetime.date.today() + datetime.timedelta(days=1)).isoformat()
    covered = _today_coverage(store, tasks, date, nights)
    need = covered < len(tasks)
    if not need:
        logger.info("[batch] 今日清单酒店已有真实数据（{}/{}），跳过", covered, len(tasks))
    return need
```

配套的覆盖率函数（`batch.py:243-245`）原文：

```python
def _today_coverage(store: PriceStore, tasks: list[dict], date: str, nights: int) -> int:
    """今天已有真实存档（非演示）的清单酒店数。"""
    return sum(1 for t in tasks if store.exists_today(t["name"], date, nights))
```

**判定语义**：逐店调用 `exists_today`，**部分覆盖也算"需要跑"**（`covered < len(tasks)`，`batch.py:263`）—— 即只要 4 家里有 1 家没数据，整批 4 家全部重跑（不用 `force` 时，已覆盖的店会在 `run_batch` 内被逐店 skip，见 §2.4）。

### 2.3 `exists_today` / `batch_ran_today` 的 SELECT-then-INSERT 原文

`storage/prices.py:88-106`（原文，**这就是任务书所指的「存档 `prices.py:88-106`」**）：

```python
    def exists_today(self, anchor_name: str, query_date: str, nights: int) -> bool:
        """今天（created_at 日期）是否已有该酒店的真实存档（排除演示数据）。"""
        with self._conn() as conn:
            row = conn.execute(
                "SELECT 1 FROM hotel_price_comparisons WHERE anchor_name=? AND query_date=? "
                "AND nights=? AND date(created_at)=date('now','localtime') "
                "AND payload NOT LIKE '%\"source\": \"演示\"%' LIMIT 1",
                (anchor_name, query_date, nights),
            ).fetchone()
            return row is not None

    def batch_ran_today(self) -> bool:
        """今天是否已成功执行过酒店批量。"""
        with self._conn() as conn:
            row = conn.execute(
                "SELECT 1 FROM hotel_batch_runs WHERE batch_date=? AND status='done' LIMIT 1",
                (datetime.now().strftime("%Y-%m-%d"),),
            ).fetchone()
            return row is not None
```

`mark_batch_run`（**纯 INSERT，无 UPDATE/UPSERT**）原文 `storage/prices.py:108-116`：

```python
    def mark_batch_run(self, batch_date: str, status: str, total: int, ok: int, failed: int,
                       details: Optional[str] = None) -> int:
        with self._conn() as conn:
            cur = conn.execute(
                "INSERT INTO hotel_batch_runs (batch_date, status, total, ok, failed, details) "
                "VALUES (?, ?, ?, ?, ?, ?)",
                (batch_date, status, total, ok, failed, details),
            )
            return int(cur.lastrowid)
```

「SELECT-then-INSERT」的实际形态是：**先 SELECT 判存在（`exists_today`）→ 不存在则 INSERT（`save`）**，两步在**不同事务、不同连接**里（`save` 用独立 `with self._conn()`，见 `storage/prices.py:68-86`），中间**没有**唯一索引/事务锁保护 → 并发下可重复插入。表上只有 `query_date` 单列普通索引（`storage/prices.py:40-42`），**没有任何 UNIQUE 约束**。

**`batch_ran_today` 是死方法**：全仓库检索仅命中 `storage/prices.py:99` 定义 + 两个测试断言（`tests/test_batch_run.py:43`、`tests/test_batch_store.py:24,28`），**生产代码零调用**。
→ 即「今天批量已经跑过」这个守卫**从未被使用**；真正被使用的守卫是 `should_run_batch`（`batch.py:275`、`bootstrap.py:129`）。

## §4 `geo.py` 全文级理解 + 为什么没生效

### 4.1 `haversine_km` 实现原文（`geo.py:8-15`）

```python
def haversine_km(lat1: float, lng1: float, lat2: float, lng2: float) -> float:
    """球面距离（公里）。"""
    r = 6371.0088
    p1, p2 = math.radians(lat1), math.radians(lat2)
    dp = math.radians(lat2 - lat1)
    dl = math.radians(lng2 - lng1)
    a = math.sin(dp / 2) ** 2 + math.cos(p1) * math.cos(p2) * math.sin(dl / 2) ** 2
    return 2 * r * math.asin(math.sqrt(a))
```

- 地球半径常量 **`6371.0088` km**（`geo.py:10`），公式为标准球面 haversine，用 `asin(√a)` 形式（比 `atan2` 版在极近点上更稳）。
- **返回值单位：公里（float，`km`）**；调用方统一 `round(..., 2)`（`base.py:116`、`runner.py:48`）。

### 4.2 `deep_find_coords` 递归策略与键名候选（`geo.py:18-60`）原文

```python
_LAT_KEYS = ("lat", "latitude", "wgs84lat")
_LNG_KEYS = ("lng", "lon", "longitude", "wgs84lng")


def _norm_coord(v: Any) -> Optional[float]:
    try:
        f = float(v)
    except (TypeError, ValueError):
        return None
    if not math.isfinite(f):
        return None
    return f


def deep_find_coords(obj: Any) -> list[tuple[float, float]]:
    """递归深搜 JSON，找同时含 lat/lng 键的对象，返回 (lat, lng) 列表（去重）。"""
    found: list[tuple[float, float]] = []
    seen: set[tuple[float, float]] = set()

    def walk(node: Any, d: int) -> None:
        if d > 12:
            return
        if isinstance(node, dict):
            lat = lng = None
            for k, v in node.items():
                lk = str(k).lower()
                if lk in _LAT_KEYS:
                    lat = _norm_coord(v)
                elif lk in _LNG_KEYS:
                    lng = _norm_coord(v)
            if lat is not None and lng is not None and (-90 <= lat <= 90) and (-180 <= lng <= 180):
                pair = (round(lat, 6), round(lng, 6))
                if pair not in seen:
                    seen.add(pair)
                    found.append(pair)
            for v in node.values():
                walk(v, d + 1)
        elif isinstance(node, list):
            for v in node:
                walk(v, d + 1)

    walk(obj, 0)
    return found
```

```python
def extract_coords_from_text(text: str) -> list[tuple[float, float]]:
    """从页面脚本/文本里用正则提取经纬度对（JSON 风格键值对，兼容引号）。"""
    found: list[tuple[float, float]] = []
    seen: set[tuple[float, float]] = set()
    for m in _COORD_PAIR_RE.finditer(text):
        pair = (float(m.group(1)), float(m.group(2)))
        if pair not in seen:
            seen.add(pair)
            found.append(pair)
    for m in _COORD_PAIR_RE2.finditer(text):

        if pair not in seen:
            seen.add(pair)
            found.append(pair)
    return found
```

### 6.2 CDP 复用语义（`browsers.py:83-92` 原文）

```python

        # 用户 Chrome：复用现有 context（共享登录 cookie），开一个新标签页
```

| --- | --- | --- |
| CDP 模式 | **复用 `browser.contexts[0]`**（用户已登录 context，共享全部 cookie/localStorage），只 `new_page()` 开新标签页 | `browsers.py:86-87` |

### 6.6 `channel="chrome"` 与回退逻辑（`browsers.py:21-54`）

```python
def launch_browser(headless: Optional[bool] = None):
    """启动/连接浏览器，返回 (playwright, browser, is_cdp)。

    配置了 CHROME_CDP_URL → 优先连接用户已登录的 Chrome；
    CDP 连接失败 → 自动降级为独立启动（不再报错，登录/采集都能继续）。
    """
    p = sync_playwright().start()
    cdp = (Config.CHROME_CDP_URL or "").strip()
    if cdp:
        try:
            browser = p.chromium.connect_over_cdp(cdp, timeout=15000)
            logger.success("已连接用户 Chrome（CDP）: {} —— 使用你已登录的会话", cdp)
            return p, browser, True
        except Exception as exc:  # noqa: BLE001
            logger.warning("连接用户 Chrome 失败（{}）——自动降级为独立启动浏览器", exc)
    use_headless = Config.HOTEL_HEADLESS if headless is None else headless
    args = [
        "--disable-blink-features=AutomationControlled",
        "--disable-infobars",
        "--no-first-run",
        "--no-default-browser-check",
    ]
    try:
        browser = p.chromium.launch(
            channel="chrome",
            headless=use_headless,
            args=args,
        )
        logger.info("已使用本机 Chrome（headless={}）", use_headless)
        return p, browser, False
    except Exception as exc:  # noqa: BLE001
        logger.warning("未找到本机 Chrome（{}），回退到 Playwright Chromium", exc)
        browser = p.chromium.launch(headless=use_headless, args=args)
        return p, browser, False
```

| 级 | 条件 | 动作 | 返回 `is_cdp` |
| --- | --- | --- | --- |
| 1 | `Config.CHROME_CDP_URL` 非空（`.env` **未配置** → 默认 `""`，`config.py:94`） | `p.chromium.connect_over_cdp(cdp, timeout=15000)` | `True` |
| 2 | 级 1 未配置或抛异常 | `p.chromium.launch(channel="chrome", headless=use_headless, args=args)` | `False` |
| 3 | 级 2 抛异常（无本机 Chrome） | `p.chromium.launch(headless=use_headless, args=args)`（Playwright 自带 Chromium，**无 `channel`**） | `False` |
| headless 取值 | `use_headless = Config.HOTEL_HEADLESS if headless is None else headless`；`Config.HOTEL_HEADLESS` 默认 **`False`（有头）** | `browsers.py:36`、`config.py:113` |
| 固定 4 个启动参数 | `--disable-blink-features=AutomationControlled` / `--disable-infobars` / `--no-first-run` / `--no-default-browser-check` | `browsers.py:37-42` |

### 8.2 09:00 日报里的比价段是怎么合并进去的（`app/pusher.py`）

**合并链（5 跳）**：

| 跳 | 位置 | 原文 / 动作 |
| --- | --- | --- |
| 1 | `pusher.py:499-510` `do_daily_group_push` | `_dispatcher().enqueue({"chatid": chatid, "push_type": "daily_report", "merge_price": True, "force": force})`（`pusher.py:507`）；`logger.info("日报推送入队 {} 个群（09:00 合并比价）", enqueued)`（`:509`） |
| 2 | `pusher.py:610-632` `PushDispatcher._worker` | 取出任务 → `push_group_now(chatid, force=..., merge_price=bool(task.get("merge_price")), push_type=...)`（`pusher.py:632`） |
| 3 | `pusher.py:454-496` `push_group_now` | 先查时段键去重（`:472`），再 `md, imgs = _hotel_daily_section(hotel, merge_price=merge_price)`（`:474`） |

**关键点**：
- 合并方式是**字符串拼接**（`md += "\n\n" + 比价段`，`pusher.py:450`），比价段成为日报**最后一段**。

- 去重键：`_push_slot()` = `YYYY-MM-DD-HH`（`pusher.py:322-324`，docstring 原文「去重时段键：YYYY-MM-DD-HH（09:00 日报与 09:00 比价合并用同一小时键）」）；`_pushed_ok` SQL 原文（`pusher.py:354-359`）：

```python

            "SELECT 1 FROM push_logs WHERE group_chatid=? AND hotel_id=? AND push_type=? "
```

```python
def _fmt_quote(q: dict) -> str:
    """单条报价文案：``name ¥price（distancekm）``；无距离则不显示距离段。"""
    text = f"{q.get('name')} ¥{_fmt_price(q.get('price'))}"
    d = q.get("distance_km")
    if d is not None:
        text += f"（{d}km）"
    return text
```

### 10.1 `get_price`（`comparator/prices.py:248`）代码原文

```python
def get_price(page, screenshot_path: Optional[Path] = None,
              use_vision: bool = True) -> dict[str, Any]:
    """取"大概最低价"：视觉优先，DOM 兜底，交叉校验。"""
    dom_price, dom_note = extract_price_dom(page)
    vision_price = None
    if use_vision and screenshot_path and Path(screenshot_path).exists():
        vision_price = vision_read_price(screenshot_path)
    cross_check = ""
    if vision_price is not None and dom_price is not None:
        diff = abs(vision_price - dom_price) / max(vision_price, dom_price, 1)
        if diff > 0.2:
            cross_check = "偏差过大，待人工确认"
    if vision_price is not None:
        return {
            "price": vision_price,
            "source": "视觉",
            "vision_price": vision_price,
            "dom_price": dom_price,
            "cross_check": cross_check,
        }
    if dom_price is not None:
        return {
            "price": dom_price,
            "source": f"DOM({dom_note})",
            "vision_price": None,
            "dom_price": dom_price,
            "cross_check": cross_check,
        }
    return {
        "price": None,
        "source": "",
        "vision_price": None,
        "dom_price": None,
        "cross_check": "",
    }
```
（`comparator/prices.py:248-282`）
